<product_requirements>
The goal is to build RETOERP, a multi-tenant SaaS platform for real estate companies. The core of the application revolves around two primary modules: a Payment Receiving module and a Payment Transfer module.

**Key Functional Requirements:**
-   **Complex Payment Schemes:** The system must allow tenants to create and manage highly customizable payment plans for properties. This includes schemes with varying durations (e.g., 12, 24 months), custom fields for special payments (e.g., initial amount), and support for both installment (EMI) and lump-sum payments.
-   **Multi-Currency Support:** The platform must handle transactions in multiple currencies (e.g., INR, USD) for international clients.
-   **Payment Processing:** Integrate Razorpay to accept online payments via UPI, cards, etc. The system must support both automatic payments through the gateway and manual entry of offline payments, with manual being the default method.
-   **Advanced Commission Management:** Implement a hierarchical commission system for sales agents. This includes project-specific commission percentages, handling of gap commissions for multi-level staff hierarchies, and automatic calculation and tracking of earned commissions upon customer payments.
-   **Free Core Features:** Web scraping for lead generation (workforce data) and the customer-facing AI chat/advisory must be implemented using 100% free technologies (e.g., BeautifulSoup, free Hugging Face models) to avoid credit-based costs.
-   **SaaS Plan Enforcement:** Tenant usage (e.g., number of projects, SMS/email volume) should be tracked and limited based on their subscription plan.
</product_requirements>

<key_technical_concepts>
- **Full-Stack Frameworks**: FastAPI (Python) for the backend, React.js for the frontend.
- **Database**: MongoDB, with Pydantic models for data validation and serialization.
- **Payment Integration**: Razorpay API for processing online payments.
- **Web Scraping**: BeautifulSoup4 for direct, free scraping of public websites (e.g., JustDial).
- **AI/LLM**: Hugging Face's free inference API as a no-cost alternative for the chatbot functionality.
- **Backend Architecture**: RESTful APIs, service-oriented structure, database seeding for master data, background tasks for scraping.
- **PWA**: Management and troubleshooting of Service Workers.
</key_technical_concepts>
