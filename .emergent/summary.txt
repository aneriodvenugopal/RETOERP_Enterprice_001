<product_requirements>
The user aims to build RETOERP (Real Estate Automation Software), a multi-tenant, GUI-based platform primarily for the Indian market, extensible globally. It features a Facebook-like UI, Laravel/Vue.js/MySQL (though React/FastAPI is currently implemented) stack, and addresses key real estate problems like lead leakage, payment chaos, and unorganized resale.

Core functionalities include:
- Multi-tenant architecture with OTP-based login and role-based permissions (Super Admin, Tenant, Staff, Customer).
- Project and Property Management: Visual layout system for properties, inventory tracking, 24-hour blocking, dynamic property types.
- Lead Management (CRM): Lead capture, assignment, follow-up, status pipeline, conversion tracking.
- Booking & Payment System: Property booking, EMI schedules, payment tracking, reminders, receipt generation.
- Commission System: Rules-based calculation, payouts, approval workflows.
- Audit Logging: Comprehensive field-level tracking.
- Multi-language & Multi-currency support.
- Referral System with coupons.
- IncomeLands: A linked web/mobile marketplace for agents to list/sell properties and customers to buy directly, with builder-specific promotional tools.
- Digital Marketing Strategy: Content marketing, free tools, SEO, paid ads, YouTube channel.
</product_requirements>

<key_technical_concepts>
- **Full-stack**: React (Frontend), FastAPI (Backend), MongoDB (Database).
- **Deployment**: Kubernetes (container), Supervisor (process management).
- **Styling**: Tailwind CSS.
- **Authentication**: OTP-based with JWT tokens.
- **Data Modeling**: UUIDs for IDs, nested document structures in MongoDB.
- **Architecture**: RESTful API, Modular Monolith (Laravel was intended, but FastAPI used).
- **Internationalization**: Foundation laid for multi-language and multi-currency.
- **Audit Logging**: Implemented via backend service and models.
- **Slug-based Categories**: Hierarchical, for flexible master data management.
</key_technical_concepts>
