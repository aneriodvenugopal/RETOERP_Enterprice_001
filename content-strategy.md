# SEO Optimization Guidelines

## Keywords Research
- Use tools: Google Keyword Planner, Ahrefs, SEMrush
- Target long-tail keywords (lower competition)
- Include location-based keywords
- Use LSI (Latent Semantic Indexing) keywords

## On-Page SEO
✅ Title tag (50-60 characters)
✅ Meta description (150-160 characters)
✅ H1, H2, H3 tags with keywords
✅ Image alt text
✅ Internal linking
✅ External linking (authority sites)
✅ URL structure (clean, keyword-rich)
✅ Schema markup

## Content Optimization
- Word count: 1500-2500 words
- Keyword density: 1-2%
- Use bullet points & lists
- Include images & videos
- Mobile-friendly
- Fast loading speed
- Clear call-to-action

## SMM Optimization

### Facebook Posts
